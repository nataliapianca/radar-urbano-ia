# Testes

Esta pasta contém os testes relacionados ao projeto Radar Urbano IA.

## Objetivos

- Testar as funcionalidades principais do sistema.
- Validar o cadastro e consulta de relatos.
- Verificar a validação dos dados recebidos pela API.
- Avaliar as respostas geradas pela IA.
- Comparar os resultados da IA com os resultados esperados.

## Tecnologias

- pytest
- Testes unitários
- Testes de integração
- Avaliação das respostas da IA (Eval)
