# Como rodar o backend - Radar Urbano IA

## Requisitos

- Python 3 instalado.
- Uma chave Geoapify para habilitar a busca de endereços. Sem ela, as outras rotas da API continuam funcionando.

## Iniciar no Windows (PowerShell)

Abra o terminal na pasta `backend` e execute:

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:GEOAPIFY_API_KEY = "SUA_CHAVE_GEOAPIFY"
uvicorn app.main:app --reload
```

Se o ambiente virtual já existir, pule `py -m venv venv`. Se as dependências já estiverem instaladas, pule `pip install`.

O servidor fica em `http://127.0.0.1:8000` e a documentação automática em `http://127.0.0.1:8000/docs`.

A chave é configurada só no terminal do backend. Não coloque a chave no frontend nem faça commit dela no GitHub. O serviço Geoapify exige uma chave para a busca de endereços; consulte o contrato da API para detalhes.

## Rotas principais

- `POST /relatos`: registra um relato com texto e localização.
- `GET /relatos`: lista os relatos.
- `GET /relatos/{id}`: consulta um relato.
- `POST /localizacoes/buscar`: busca coordenadas a partir de um endereço.
- `PUT /relatos/{id}/classificacao`: recebe a classificação gerada pela Frente 3.

Os relatos são mantidos em memória e desaparecem quando o servidor reinicia. A busca de endereço retorna opções; o usuário precisa confirmar uma delas antes de cadastrar o relato.
