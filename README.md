# 🏙️ Radar Urbano IA

Plataforma inteligente para registro, classificação e priorização de problemas urbanos, feita para a disciplina **Projeto Integrador IV** (FAESA).

> Viu um problema na sua rua? Conte do seu jeito — a IA organiza, prioriza e encaminha pra quem resolve.

## 📋 Sobre

Usuários relatam problemas urbanos (buraco, poste apagado, lixo, etc) em linguagem natural. Um modelo de IA (LLM) classifica o relato em **categoria**, **prioridade** e **setor responsável**, exibindo tudo num mapa e dashboard.
